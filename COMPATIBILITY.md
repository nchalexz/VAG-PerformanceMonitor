# Совместимость

Матрица ведётся честно: «не проверено» — это не «работает». Пустые клетки
означают отсутствие проверки, а не поддержку.

## Приложение

| Параметр | Значение |
|---|---|
| `applicationId` | `io.github.nchalexz.aaperfmon` |
| Версия | 0.5.0 (versionCode 6) |
| Сборки | `standard` (без Android Auto), `aa` (с Car App Library) |
| Один `applicationId` | да, сборки заменяют друг друга при установке |
| Минимальная Android | 7.0 (API 24) |
| Целевая Android | 16 (API 36) |
| GMS | не требуется |
| Архитектуры | универсальный APK, собственного нативного кода нет |
| Установка рядом с VAG Diag | да, отдельный `applicationId` |
| Foreground-служба | да, тип `connectedDevice`, постоянное уведомление |

## Поверхности

| Поверхность | Состояние |
|---|---|
| Приборка (`CockpitActivity`) | работает на эмуляторе Android 15; на реальном устройстве не проверялась |
| Виджет «Телеметрия AA» | размещён на лаунчере эмулятора Android 15; конфигуратор работает; обновление значений при живом соединении не проверялось |
| Android Auto (`CarAppService`) | собирается в `aa`; на головном устройстве и в DHU не проверялся |
| AARE | отдельной интеграции нет; на конкретном хосте и разрешении не проверялся |
| Диагностический экран VAG Diag | унаследован; на живом автомобиле не проверялся |

## Автомобили

| Автомобиль | Платформа | Состояние |
|---|---|---|
| VAG MQB (целевая платформа) | MQB | целевой профиль; **на машине не проверялся** |
| Другие MQB | MQB | теоретически применимы стандартные PID; не проверялись |
| MQB Evo, MQB A0, MLB, MLB Evo, PQ35, PQ46, MEB | — | не поддерживаются: нет профилей и проверенных DID |

Комплектация и прошивка конкретного автомобиля могут менять набор доступных
PID. Это выясняется диагностикой, а не предполагается по модели.

| ELM327 Bluetooth SPP | RFCOMM | код унаследован; на живом адаптере **не проверялся** |
| ELM327 USB (CH340, FTDI, CP210x, PL2303) | USB OTG | код унаследован; на живом адаптере **не проверялся** |

| TP2.0 | не поддерживается |

## Сигналы

| Группа | В каталоге | Проверено на машине |
|---|---:|---:|
| Двигатель | 34 | 0 |
| Температуры | 13 | 0 |
| Топливо | 20 | 0 |
| Экология | 4 | 0 |
| Электрика | 1 | 0 |
| Диагностика | 27 | 0 |
| Трансмиссия | 30 | 0 |

Из 129 сигналов: 41 OBD-II PID, 4 вычисляемых, 1 виртуальный, 83 VAG UDS
из OBDb/Audi-Q3 (CC BY-SA 4.0). Все VAG-сигналы — «декодирован», ни один
не «подтверждён».

Конкретный блок может не поддерживать часть PID. Приложение показывает
«—» (значение было, но устарело) или `N/A` (успешного чтения ещё не было)
и не подставляет ноль. Передача показывается как P/R/N/1…, но соответствие
смещения −2 на живом MQB TDI не проверялось.

## Что не заявляется

- Совместимость с конкретной моделью VAG до проверки на ней.
- Чтение передач, моментов и температур DSG/Haldex через OBD-II: только через VAG DID, и это не проверено на машине.
- Произвольный Canvas в Android Auto: доступны только шаблоны хоста.
- Подтверждённые VAG DID: 83 сигнала декодированы по открытому набору, но не проверены на MQB TDI.
- Публикация Android Auto в Google Play: нужен белый список хостов
  и проверка категории.
- Готовая интеграция с AARE.
- Работа на автомобилях до 2010 года (TP2.0).
- Работа через BLE-адаптеры.
- Одновременная установка сборок `standard` и `aa`: у них один
  `applicationId`.
