**Дата:** 26 ноября 2026
**Версия:** 0.4.0, `versionCode` 4
**Статус:** тестовая сборка. Не проверена на автомобиле, головном устройстве
Android Auto и живых адаптерах Bluetooth/USB.

0.4.0 — это новый интерфейс по двум макетам и первые VAG-специфичные
параметры MQB TDI через UDS. Каталог вырос с 45 до 129 сигналов, но ни один
не подтверждён на машине: 128 имеют статус «декодирован», 1 — «описан».

## Что изменилось

- **Два экрана вместо трёх.** Главный: три аналогово-цифровых прибора
  и пять плиток. Расширенный: те же приборы меньше, категории и адаптивная
  сетка. Каталог открывается поверх приборки. Свайп, переход с прибора
  в категорию, сохранение категории.
- **Дуга заполнения и единицы.** У прибора между кольцами рисуется сегмент
  от начала шкалы до стрелки. В плитке единица стоит сразу под значением,
  а не у нижнего края.
- **Дневная и ночная темы**, английские и русские подписи. По умолчанию
  английский, на русской системе — русский; ручной выбор в настройках.
- **83 VAG-сигнала MQB TDI через UDS `22 <DID>`** из открытого набора
  OBDb/Audi-Q3 (CC BY-SA 4.0, commit `b51e835`): наддув, рампа, коррекции
  форсунок, температуры DSG и сцеплений, давления K1/K2, сажа и температуры
  DPF, выхлоп, датчик АКБ, масло из блока двигателя и щитка.
- **Расход л/100 км** из PID `0x5E` и `0x0D`; на стоянке — «—».
- **Портретная раскладка телефона** исправлена: приборы не висят в пустой
  панели, плитки не растягиваются на всю высоту.

## VAG UDS

Читаются только `22` (ReadDataByIdentifier) и `3E` (keep-alive). Расширенная
сессия `10 03`, кодирование, адаптации и тесты исполнительных механизмов
не отправляются. DIDs, которым нужна такая сессия, в набор не попали.

Адреса блоков: двигатель `7E0/7E8`, коробка `7E1/7E9`, щиток `714/77E`,
датчик АКБ `710/77A`. Ответ на DID кэшируется на 250 мс, следующий OBD-запрос
возвращает заголовок `7DF`.

**Честно:** формулы взяты из открытого набора, а не проверены на живом
MQB TDI. Конкретный блок может отказать в DID или ответить другой длиной.
На дизеле PID `0x5C` часто молчит, поэтому температура масла на главном
экране падает обратно на VAG `11BE`, затем на щиток `202F`.

## Android Auto

AA-сборка по-прежнему показывает **`ListTemplate`** — шаблонный список
состояния и до восьми параметров профиля. Штатный хост не разрешает
произвольный Canvas: полные два экрана в AA технически невозможны.
Полноэкранная приборка предназначена для AARE/DashGrid и обычного телефона.

## Установка

Сборки заменяют друг друга: у них один `applicationId`.

| Сборка | Что внутри | Размер |
|---|---|---|
| `standard` | приборка, виджет, диагностика; без Android Auto | ≈18,8 МБ |
| `aa` | то же плюс Android Auto (Car App Library) | ≈20,1 МБ |

```sh
adb install -r AA-Performance-Monitor-0.4.0-standard.apk
adb install -r AA-Performance-Monitor-0.4.0-AA.apk
```

## Что проверено

| Проверка | Как | Результат |
|---|---|---|
| Сборка `standard` и `aa` | `./gradlew assembleStandardDebug assembleAaDebug` | да |
| 50 JVM-тестов | `./gradlew testStandardDebugUnitTest testAaDebugUnitTest` | да, 0 падений |
| VAG UDS: разбор DID и переключение заголовков | поддельный ELM327, JVM-тест | да |
| Главный, расширенный экран, каталог, темы и языки | эмулятор Android 15, 1920×720 | да |
| Портретная раскладка телефона | эмулятор Android 15, 1080×2400 | да |
| Реальный автомобиль | MQB TDI | нет |
| Головное устройство Android Auto / DHU | реальный хост | нет |
| AARE / DashGrid | конкретный хост | нет |
| Живые Bluetooth/USB-адаптеры | железо | нет |

Тесты, ДЕМО и эмулятор **не являются** подтверждением совместимости.

## Ограничения

- 83 VAG DID декодированы, но не подтверждены на MQB TDI.
- Нет `10 03`, Haldex, AdBlue и части DPF-параметров.
- Нет записи поездок, истории, графиков и конструктора дашбордов.
- Android Auto — только шаблонный список.
- Профили выбираются вручную; определения по VIN нет.
