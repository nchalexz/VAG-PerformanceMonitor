**Дата:** 27 ноября 2026
**Версия:** 0.6.0, `versionCode` 8
**Статус:** тестовая сборка. Планировщик, актуальность данных и метрики
проверены 98 JVM-тестами; на живом ELM327 и на автомобиле 0.6.0 ещё
не запускалась. Живая проверка 0.5.1 (ELM327 v1.5, OBD PID и один VAG DID)
относится к предыдущему ядру опроса.

0.6.0 переводит опрос телеметрии на единый адаптивный планировщик. Раньше
движок выбирал «самый давно прочитанный просроченный сигнал» и не знал ни
фактической задержки адаптера, ни того, что параметр перестал отвечать.
Теперь у каждого параметра есть приоритет, свой интервал, история отказов
и срок актуальности; значения перестают быть «свежими» сами, без нового
ответа, а одиночный таймаут не превращает число в прочерк.

## Что добавлено

- **Приоритеты.** P0 — обороты, скорость, наддув, температура масла и ОЖ;
  P1 — момент, мощность, передача, педаль, давление топлива; P2 — остальное.
  Насыщенная шина сначала обслуживает P0.
- **Адаптивные интервалы.** Интервал растёт, если адаптер отвечает медленнее
  целевой частоты; при перегрузке замедляются P2, затем P1.
- **Честные отказы.** Таймаут, отрицательный ответ UDS и сбой транспорта
  различаются. Параметр, который перестал отвечать, опрашивается реже
  (до 15–30 с) и периодически перепроверяется, а не выпадает навсегда.
- **Один канал.** Пакетное чтение нескольких DID одного блока включается
  только после успешной проверки; иначе источник читает по одному.
- **Актуальность.** `VALID`, `STALE`, `NEVER_READ`: число, «—» после 5 с
  (P0/P1) или 30 с (P2), `N/A` до первого успешного чтения. Возраст считается
  по монотонным часам и проверяется даже при потере связи.
- **Диагностика.** Фактическая частота каждого параметра, средняя и P95
  задержки, запросы/с, процент успеха, таймауты, переключения ECU, переходы
  в «устарело», глубина очереди. Журнал экспортируется в JSON из настроек.
- **Передача.** Позиция селектора показывается как P, R, N, 1…; шкала для
  неё не рисуется. Смещение −2 из открытого набора OBDb на автомобиле
  не проверялось — P/R/N нужно сверить первыми.
- **Одна транзакция шины.** `AdapterBus` не даёт диагностике и телеметрии
  перемешивать команды: скан блоков и чтение ошибок занимают адаптер целиком.

## Установка

| Сборка | Что внутри | Размер |
|---|---|---|
| `standard` | Приборка, виджет, диагностика; без Android Auto. | ≈18,9 МБ |
| `aa` | То же плюс Android Auto (Car App Library). | ≈20,2 МБ |

Требования: Android 7.0+ (API 24), ELM327 по Wi-Fi, Bluetooth SPP или USB.
Сборки используют один `applicationId` и заменяют друг друга.

1. Скачайте нужный APK со страницы [Releases](https://github.com/nchalexz/VAG-PerformanceMonitor/releases).
2. Разрешите установку из неизвестных источников.
3. При обновлении с 0.5.1 подпись изменится: может потребоваться удалить
   старую сборку (настройки при этом теряются).

```sh
adb install -r VAG-Performance-Monitor-0.6.0-standard.apk
adb install -r VAG-Performance-Monitor-0.6.0-AA.apk
```

SHA-256 опубликованных файлов лежит в `SHA256SUMS.txt` рядом с APK.
Сертификат подписи — в разделе Install файла [README](../README.md):
сборка CI подписана отладочным ключом, поэтому отпечаток отличается
от предыдущих версий.

## Как измерить частоту на реальном адаптере

1. Подключите ELM327 и откройте приборку: подписка экрана задаёт набор P0/P1.
2. Откройте **Настройки → Диагностика телеметрии** и дайте опросу идти
   2–3 минуты.
3. Нажмите **Экспорт журнала** и передайте JSON на компьютер.
4. В `metrics.signals` смотрите `updatesPerSecond` (фактическая частота),
   `timeouts` и `ageMs`; в `metrics` — `requestRateHz`, `p95LatencyMs`
   и `successPercent`; в `schedule` — рассчитанные интервалы и паузы.
5. Целевые 10 Гц для оборотов считаются достигнутыми только если
   `updatesPerSecond` близко к 10 на этом конкретном адаптере и машине.

## Ограничения

- На реальном автомобиле 0.6.0 не проверялась: ни частоты, ни пакетное
  чтение DID, ни P/R/N.
- Прошивка блока может не поддерживать пакетный `22 DID1 DID2`; тогда
  приложение автоматически возвращается к одиночным запросам.
- Диагностический экран во время сканирования занимает шину целиком:
  приборка на это время замирает, значения уходят в «—» по сроку давности.
- Экспорт журнала содержит технические числа и названия сигналов; VIN,
  координаты и содержимое памяти блоков в него не попадают.
