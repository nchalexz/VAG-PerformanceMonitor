**Дата:** 27 ноября 2026
**Версия:** 0.6.1, `versionCode` 9
**Статус:** тестовая сборка. 0.6.0 запускалась на реальном телефоне (Huawei,
Android 12) с мок-ELM327 по Wi-Fi: LIVE, OBD PID читаются. На живом
адаптере автомобиля и в поездке ни 0.6.0, ни 0.6.1 не проверялись.

0.6.1 — небольшая сборка поверх нового ядра опроса из 0.6.0. Она убирает
две бытовые помехи и одно недоразумение с передачей.

## Что исправлено

- **Адаптер запоминается сразу при выборе**, а не только после успешного
  подключения. Повторно открыв настройки, вы увидите тот же адаптер,
  а не пустое «Выберите устройство».
- **Список устройств больше не перечисляется при каждом входе.** Он
  загружается только по кнопке «Выбрать другой» или «Обновить»; при
  обычном открытии показывается сохранённый адаптер.
- **Передача не тратит запросы.** `vehicle.gear` — виртуальный сигнал,
  стандартного PID для передачи нет. Раньше живой источник опрашивал его
  вхолостую и показывал «не поддерживается»; теперь он не попадает
  в очередь. В ДЕМО передача по-прежнему берётся из модели.
- **Передача из DSG polling P1.** DID `210F` опрашивается чаще, когда
  открыта вкладка «КП», и остаётся запасным источником на приборке.

## Почему передача может быть N/A

Передачу не отдаёт ни один стандартный OBD-II PID. Единственный источник
в приложении — блок коробки передач (`7E1`, DID `210F`). Если блок:

- не отвечает (например, это мок-адаптер без второго блока);
- отвечает отрицательно (DID не поддерживается прошивкой);
- требует расширенную сессию `10 03`, которую приложение не открывает
  из-за режима «только чтение»,

то плитка честно показывает `N/A`. P/R/N — следствие смещения −2 из
открытого набора OBDb; на живом DSG это ещё не проверялось.

Если на автомобиле передача нужна, проверьте в экспортированном журнале
(`Настройки → Диагностика телеметрии → Экспорт журнала`) запись
`vag.7e1.210f.gear`: `timeouts` и `negativeResponses` покажут, молчит блок
или отказывает в DID.

## Установка

| Сборка | Что внутри | Размер |
|---|---|---|
| `standard` | Приборка, виджет, диагностика; без Android Auto. | ≈18,9 МБ |
| `aa` | То же плюс Android Auto (Car App Library). | ≈20,2 МБ |

У сборок один `applicationId`: ставится только одна. Каждая сборка CI
подписывается новым отладочным ключом, поэтому обновление с 0.6.0 или
0.5.1 может потребовать удаления старой версии (настройки теряются).

```sh
adb install -r VAG-Performance-Monitor-0.6.1-standard.apk
adb install -r VAG-Performance-Monitor-0.6.1-AA.apk
```

SHA-256 опубликованных файлов — в `SHA256SUMS.txt` на странице релиза.

## Проверено

- 100 JVM-тестов, включая все 12 сценариев задания и новые проверки:
  виртуальный сигнал не опрашивается живым источником, ДЕМО показывает
  передачу.
- 0.6.0 на телефоне с мок-ELM327 по Wi-Fi: LIVE, PID читаются, значения
  совпадают с моделью мока (обороты, скорость, ОЖ, масло, наддув,
  топливо). Передача `N/A` — у мока нет блока `7E1`.
- Целевые частоты не заявляются достигнутыми: нужен замер на реальном
  адаптере.
