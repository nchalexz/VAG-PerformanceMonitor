# VAG Performance Monitor 0.5.0

<p align="center">
  <img src="https://raw.githubusercontent.com/nchalexz/VAG-PerformanceMonitor/main/docs/assets/banner.svg" width="100%" alt="VAG Performance Monitor — телеметрия VAG через обычный ELM327">
</p>

**Дата:** 27 ноября 2026
**Версия:** 0.5.0, `versionCode` 6
**Статус:** стабильная тестовая сборка. Проверена на эмуляторе Android 15;
на автомобиле, головном устройстве Android Auto и живом адаптере — нет.

0.5.0 добавляет **read-only мост телеметрии для DashGrid**: другое приложение
может прочитать текущие значения через обычный `ContentProvider`, не открывая
второе OBD-соединение. ELM327, VAG UDS, приборка, виджет и AA-сборка остаются
прежними; `TelemetryService` и `CockpitActivity` по-прежнему не экспортированы.

## Что добавлено

- `ContentProvider` `io.github.nchalexz.aaperfmon.bridge.TelemetryProvider`,
  authority `io.github.nchalexz.aaperfmon.telemetry`, метод
  `call("snapshot")` → `Bundle` контракта v1.
- Разрешение `io.github.nchalexz.aaperfmon.permission.READ_TELEMETRY`
  (`protectionLevel="normal"`); проверка ещё раз внутри `call`.
- Снимок: `version`, `connection`, `status`, `source`, `updatedAt`, `signals`
  (JSON, до 128 элементов). Значения — в единицах приборки: наддув в bar,
  европейская запятая, категории Engine / Temperatures / Fuel / Gearbox /
  Turbo / Diagnostics в порядке экрана.
- Подписи и единицы — на языке самой приборки; `updatedAt` — самый свежий
  `timestampMs` из отданных сигналов, `0` без данных.
- Автоподключение вынесено из `Telemetry.init` в `Telemetry.autoConnectOnce()`,
  поэтому чтение снимка не запускает службу и не открывает OBD. В ДЕМО
  провайдер отдаёт значения той же демонстрационной модели с плашкой `demo`.

## Установка

| Сборка | Что внутри | Размер |
|---|---|---|
| `standard` | приборка, виджет, диагностика, read-only мост; без Android Auto | ≈18,8 МБ |
| `aa` | то же плюс Android Auto (Car App Library) | ≈20,1 МБ |

adb install -r VAG-Performance-Monitor-0.5.0-standard.apk
adb install -r VAG-Performance-Monitor-0.5.0-AA.apk

## Проверка

- 61 JVM-тест, 0 падений; задачи `test` для `standard` и `aa` зелёные;
  `assembleStandardDebug` собирается.
- На эмуляторе Android 15 (API 35) с релизным APK 0.5.0:

  ```sh
  adb shell content call \
    --uri content://io.github.nchalexz.aaperfmon.telemetry \
    --method snapshot
  ```

  вернул `version=1`, 128 сигналов во всех шести категориях и растущий
  `updatedAt` между вызовами; `connection=demo`.
- DashGrid 1.3.0 с этим APK нарисовал приборку, значения совпали со снимком,
  `dumpsys package io.dashgrid.app` показал
  `READ_TELEMETRY: granted=true`, в `adb logcat` не было второго
  ELM327/OBD-соединения и `SecurityException`.
- VPM 0.4.1 без моста даёт в DashGrid карточку «Update VPM», отсутствующий
  VPM — «Install»; после установки 0.5.0 DashGrid нужно один раз обновить,
  чтобы Android выдал normal-разрешение.
- Не проверено: реальный автомобиль, ELM327, головное устройство, Android Auto
  на живом хосте, экран приборки на телефоне. ДЕМО-значения не являются
  подтверждением совместимости с автомобилем.
