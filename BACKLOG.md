# Бэклог

Приоритеты: **P0** — без этого нельзя считать первую итерацию проверенной;
**P1** — следующий содержательный шаг; **P2** — расширение.

## P0

| Задача | Зачем |
|---|---|
| Проверить приложение на Golf 7.5 | все сигналы сейчас `DECODED`, ни один не `CONFIRMED`; без машины это не исправить |
| Сверить поддерживаемые PID с блоком CUNA | 0x5C, 0x61–0x63, 0x23 могут отсутствовать |
| Проверить экран на Huawei Mate X3 | Compose-вёрстка не запускалась на устройстве |
| Проверить Bluetooth и USB на живых адаптерах | в базовом проекте они не проверены |
| Отключение адаптера при открытой приборке | сейчас источник остаётся с закрытым соединением и показывает «—»; нужно переключаться на ДЕМО и сообщать причину |
| Решить судьбу ручного стирания ошибок | ТЗ требует read-only; в унаследованном экране кнопка есть |
| Подключить ELM327-emulator к тестам | проверить разбор реальных ответов, а не только поддельного источника |
| Зафиксировать версию `usb-serial-for-android` и хеш | JitPack — риск цепочки поставок |

## P1

| Задача | Зачем |
|---|---|
| Профили автомобилей и определение по VIN | без этого каталог не подстраивается под машину |
| Расширенные DID VAG в движке | температуры DSG, Haldex, DPF, наддув из блока двигателя |
| Импорт OBDb (JSON) с проверкой лицензий | расширение каталога без выдумывания |
| Запись поездок и экспорт CSV/JSON | требование ТЗ, полезно для отладки сигналов |
| Конструктор дашбордов | главная продуктовая функция после телеметрии |
| Настройка единиц и точности | бар/кПа, л/100 км, °C/°F |
| Экран Vehicle Health | температуры, коррекции, DSG, Haldex, ошибки |
| Foreground Service для телеметрии | приборка не должна умирать при сворачивании |
| Автопереподключение без перезапуска | требование ТЗ |
| Убрать `ACCESS_FINE_LOCATION` из запроса на старых Android | разрешение не объявлено в manifest и не нужно цели |

## P2

| Задача | Зачем |
|---|---|
| AARE / автомобильный экран | проекция на головное устройство |
| Штатный Android Auto | исследовать ограничения категорий, не обещать заранее |

## Технический долг

- Один Gradle-модуль: разделение на `core`/`features` отложено до второго
  потребителя телеметрии.
- `Elm327.command` синхронизирован, но диагностика и телеметрия всё ещё
  конкурируют за шину логически. Нужна общая очередь запросов с
  приоритетами.
- Дублирование форматирования значений между приборкой и Live Data.
- Нет скриншот-тестов Compose.
- `README` базового проекта описывает функции, которых в этом форке может
  не быть; документацию нужно синхронизировать по мере изменений.
