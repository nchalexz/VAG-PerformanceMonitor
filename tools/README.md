# tools

## VAG-сигналы из OBDb

`obdb_import.py` собирает `telemetry/VagSignals.kt` из открытого набора
[OBDb/Audi-Q3](https://github.com/OBDb/Audi-Q3) (signalsets v3, коммит
`b51e835`, лицензия CC BY-SA 4.0).

Файл `obdb-audi-q3.json` — выбранные команды исходного набора, а не весь
набор. Так репозиторий не разрастается, а каждое изменение данных видно
в diff.

Перегенерация:

```bash
python3 tools/obdb_import.py
```

Скрипт выбирает только команды `22 <DID>` без `dbg` и без требования
расширенной сессии `10 03`, с живыми числовыми величинами. Сигналы без
подтверждения на автомобиле остаются со статусом «декодирован»: наличие
формулы в открытом наборе — не проверка на MQB TDI.

Данные OBDb распространяются по CC BY-SA 4.0; атрибуция — в
`THIRD_PARTY_NOTICES.md`. Код приложения остаётся под MIT.

## Баннер README

`render_banner.py` собирает `docs/assets/banner-en.png` (1600×600) для
английского README. В баннере одно окно с реальным скриншотом
`screen-driving.png`; кодом нарисованы только фон, мягкая тень и подписи,
без рамок и обводок. Это не макет интерфейса и не снимок устройства:
данные на экране — Demo Mode.

Нужны Pillow и NumPy. Перегенерация:

```bash
python3 tools/render_banner.py
```
