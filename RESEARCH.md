# Исследование источников

Состояние на 0.2.0. В этой итерации глубоко изучен только базовый проект;
остальные репозитории из ТЗ ещё не разбирались. Ниже нет выдуманных
commit SHA, файлов и «найденных» функций: если источник не открывался,
так и написано.

## Изучено

### gdm0991/vagdiag — база диагностического ядра

| Параметр | Значение |
|---|---|
| Ссылка | https://github.com/gdm0991/vagdiag |
| Commit | `c2d565fb27deedb645b6ee38ea0fd724cb269d64` |
| Лицензия | MIT |
| Языки | Kotlin (Android), Python (настольная версия) |
| Решение | Форк; ядро сохранено, телеметрия и приборка добавлены |

Что найдено в Android-версии:

| Файл | Функциональность | Переиспользование |
|---|---|---|
| `core/Transport.kt` | Wi-Fi TCP, Bluetooth SPP, USB-serial (CH340/FTDI/CP210x/PL2303), подбор скорости USB | взято целиком |
| `core/Elm327.kt` | инициализация адаптера, снятие фильтра, повтор при «занят», самовосстановление после серии пустых ответов, сборка ISO-TP | взято; добавлена синхронизация `command` |
| `core/Uds.kt` | UDS-клиент VAG, три способа дочитать длинный ответ, отрицательные ответы, коды DTC | взято без изменений |
| `core/Codes.kt` | словарь описаний кодов | взято |
| `DiagViewModel.kt` | подключение, поиск блоков, ошибки, OBD-II, мониторинг, отчёт | взято; добавлена передача адаптера в `AdapterHolder` |
| `ui/Screens.kt` | диагностические экраны | взято |
| `app/mock_elm327.py` | программная заглушка адаптера для проверки полного цикла | не включена в APK, полезна для ручных прогонов |

Ограничения базового проекта, которые наследуются:

- нет TP2.0 (VAG примерно до 2010 года);
- дешёвые ELM327-клоны могут не дочитывать длинные ответы блоков кузова;
- Bluetooth и USB не проверены автором базового проекта на живых адаптерах;
- приложение ориентировано на сервисную диагностику, а не на непрерывную
  телеметрию: постоянного опроса PID и приборных панелей нет.

Почему ядро не переписывалось: оно содержит дорого выясненные особенности
дешёвых адаптеров (чистка буфера, повтор при занятости, отказ от `ATCRA`
без параметра, пауза между выборками ошибок). Эти знания подтверждены
живым автомобилем и должны быть сохранены.

### Стандарты

| Источник | Что взято | Статус |
|---|---|---|
| SAE J1979 / ISO 15031-5 | перечень OBD-II PID, формулы, единицы | формулы общедоступны; использованы для 41 сигнала |
| ISO 15765-4 / ISO-TP | формат кадров, сборка длинных ответов | реализовано в базовом ядре |
| ISO 14229 (UDS) | сервисы 0x22, 0x19, 0x14, отрицательные ответы | используется диагностикой |
